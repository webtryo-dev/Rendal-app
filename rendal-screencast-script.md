# Rendal — App Store Screencast Script (target: ~5-6 min, within the 3-8 min window)

Note: Rendal has no storefront-facing feature — it's 100% an embedded merchant/admin tool, so there's no separate "customer flow" to show. The whole video is the merchant flow; that's expected and fine.

Recording tips: use a dev store with real-looking product/order data (not an empty store — answers look thin otherwise), quiet room, narrate what you're doing as you click rather than leaving silent gaps, close other browser tabs so the recording looks clean.

---

## 0:00–0:20 — Intro
One sentence on camera or in voiceover: "This is Rendal, an AI co-founder that lives inside Shopify admin and helps merchants manage products, discounts, shipping, and more through chat." Show the app icon/name in the Apps sidebar.

## 0:20–0:50 — Install and onboarding
Click the install link, let Shopify's OAuth grant screen appear, approve the requested permissions. Narrate: "Standard Shopify OAuth — no separate account needed."

## 0:50–1:20 — Mandatory plan selection
Show the redirect to Shopify's own hosted plan-selection page. Pick a plan (Growth or Starter is fine for the demo). Narrate: "Merchants choose a plan through Shopify's own billing page before using the app — nothing custom-built here, this is Shopify App Pricing."

## 1:20–1:40 — Landing on Chat
After choosing a plan, show it redirect straight into the Chat tab. Point out the model switcher at the top (Claude / GPT / Gemini).

## 1:40–2:30 — Read-only question
Ask something like "What are my best-selling products this month?" or "List my products." Let it fully answer. Narrate that this is read-only — no approval needed for questions.

## 2:30–4:00 — The approval flow (core feature — spend the most time here)
Ask for an actual change: "Raise the price of [a real product] by 10%" or "Create a 10% off discount code called TEST10." Show the review card appearing with the proposed change clearly laid out. Click **Approve**. Switch to a second browser tab showing Shopify Admin's Products or Discounts page and refresh to prove it actually saved. This is the single most important thing to show clearly — it's the app's core safety promise.

## 4:00–4:30 — Discard, briefly
Ask for one more change, this time click **Discard** instead, and note nothing changed. Keep this quick — 20-30 seconds is enough.

## 4:30–5:00 — Attachments
Click the attach icon, upload a product image or a PDF, ask a quick question about it.

## 5:00–5:45 — Skills
Open the Skills tab, upload a short .md file as a custom skill. Back in Chat, type "/" followed by that skill's trigger to run it.

## 5:45–6:15 — Model switching mid-conversation
In the same thread, switch the model dropdown to a different provider and ask a follow-up question, showing the reply now comes from the new model while context carries over.

## 6:15–6:45 — Usage and plan switching
Open the Usage tab, show the current plan and remaining credits, then click "Switch plan" to show it opens Shopify's own plan page — proving merchants can upgrade/downgrade without contacting support.

## 6:45–7:00 — Close
One closing line: "That's Rendal — an AI co-founder for running the day-to-day of a Shopify store, with every write action reviewed before it saves."

---

Total: ~7 minutes as scripted — trim the Discard beat and/or the attachments beat if you need to land closer to 5-6.
