# Rendal — Video Editor Brief (Motion Graphics Promo)

## What Rendal is

Rendal is an AI co-founder that lives inside the Shopify admin as an embedded app — not a separate website or dashboard. A merchant opens it from their Shopify Apps menu and gets a chat panel where they can ask questions about their store (sales, inventory, discounts) and ask for changes to be made (prices, discount codes, shipping rates, inventory). Every write action shows a review card first — nothing saves until the merchant clicks Approve. It supports three AI model providers (Claude, GPT, Gemini) switchable mid-conversation, and merchants can upload custom "Skills" (instruction files) triggered with a slash command.

Target audience: Shopify store owners/operators, mostly non-technical, who want day-to-day store tasks handled faster without hiring a developer or digging through admin menus themselves.

## Brand look

- Colors: void black `#0A0A0F`, navy `#0B1E3D` / `#0F2650`, signal blue `#2D6CFF` (primary accent), glow blue `#5B8DFF` (highlights/glow), offwhite `#F5F6FA` (text on dark).
- Fonts: Space Grotesk for headlines/on-screen text, Inter for body copy, JetBrains Mono for anything data/code-like (credits, numbers).
- Overall feel: dark, confident, technical SaaS — no stock photos of people, no clutter, glow/gradient accents in signal blue only.

## How to get real app footage: set up a Shopify development store

The motion graphics should be built around **real screen captures of the actual app**, not mockups — this also matches what's already been used for the App Store screenshots, so the video and the listing look consistent.

1. **Get a Shopify Partner account** (free): go to partners.shopify.com and sign up if you don't already have access to the one this project uses. Ask Youssef for an invite to the existing Partner organization instead of creating a separate one, so everything stays under one account.
2. **Create a development store**: inside the Partner Dashboard, go to Stores → Add store → Development store. Give it any name — this is a free sandbox store, not a real one, so it's fine to populate with test data.
3. **Add sample data so it doesn't look empty on camera**: in the new dev store's admin, use Shopify's built-in sample data generator (Settings → or search "sample data" in admin search) to add realistic-looking products, or add 8-10 products yourself with real product photos and varied prices so the chat's answers about "best-sellers" or "low stock" look convincing on screen.
4. **Install Rendal on the dev store**: ask Youssef for the current install link (from the Partner Dashboard's app listing → Overview → "Test on development store"), open it while logged into the new dev store, and go through the install flow.
5. **Choose a plan**: Rendal now requires picking a plan (any tier) via Shopify's own hosted plan page right after install before landing on Chat — this is expected, just pick any plan to continue.

## What to actually capture

Work through the app once yourself before recording, so you know what a natural-looking session feels like. Then capture screen recordings (not just static screenshots — this is a video) of:

- The Chat tab with the model switcher visible, asking a real question ("What are my best-selling products?") and getting a full answer.
- Asking for a change ("Raise the price of [a product] by 10%") and the approval card appearing with a clear before/after — this is the single most important clip, since it's the app's core trust story. Capture the Approve click too.
- The model switcher dropdown open, showing Claude/GPT/Gemini as options.
- The Skills tab with a custom skill uploaded, then typing "/" in the composer and a skill suggestion appearing.
- The Usage tab showing plan and credits, and the "Switch plan" button.

Crop out all browser chrome (address bar, tabs) and any desktop background before using a clip — same rule as the App Store screenshots. If any test data on screen looks like it could pass as a real customer's name or email, swap it for placeholder data first.

Pick whichever specific moments look cleanest and most legible at video resolution — you have discretion on exact framing/timing, the beat table is a guide, not a rigid shot list.
